Firmar Caaguazú Go para iPhone

Desde Windows, sin Mac. Unos 15 minutos. Un script te va guiando y abre cada página.

Antes: dos programas y una sesión

  • Git para Windows — git-scm.com (trae OpenSSL, que usa el script).
  • GitHub CLI — cli.github.com. Después, en PowerShell, una sola vez:
gh auth login
  • En GitHub, que el PR #32 (versión 1.7.0) esté mezclado.

El único comando

En PowerShell, dentro de la carpeta del repositorio:

cd docs\app-store
powershell -ExecutionPolicy Bypass -File .\firmar-facil.ps1

El script abre cada página en el navegador y espera. Vos hacés lo de la web, apretás Enter, y él encuentra solo los archivos en Descargas.

1Team ID

Se abre tu cuenta de Apple. En Membership details copiá el Team ID (10 letras y números) y pegalo en la ventana.

2Registrar la app

App IDs → App. Description: Caaguazu Go. Bundle ID: Explicit → net.caaguazu.turismo → Continue → Register. Enter.

3Certificado

Te pide tu correo y tu nombre, y se abre la carpeta con solicitud.certSigningRequest. En la página: Apple Distribution → Continue → subí ese archivo → Continue → Download. Enter.

4Perfil

En Distribution elegí App Store Connect → Continue → net.caaguazu.turismo → el certificado del paso 3 → nombre Caaguazu App Store → Generate → Download. Enter.

5Clave para subir a Apple

Team Keys → +. Name: GitHub. Access: App Manager → Generate → Download. Enter. Después pegá el Issuer ID: el código largo con guiones que está arriba de la tabla de claves. El Key ID lo saca solo.

Apple deja bajar esa clave una sola vez. El script la copia a tu carpeta firma-ios.

6Cargar en GitHub

Lo hace solo. Tiene que decir «cargado» siete veces.

7Crear la app y compilar

Se abre App Store Connect. Apps → + → New App: nombre Caaguazú Go, idioma Spanish (Mexico), el bundle de la lista, SKU caaguazu-turismo. Volvé a la ventana y apretá Enter: arranca la compilación. En ~25 minutos aparece en TestFlight.

Guardá la carpeta C:\Users\TU_USUARIO\firma-ios en un pendrive y no la mandes a nadie: ahí está la clave privada del certificado. Sin ella hay que hacer todo de nuevo.

Si algo sale mal

«No encuentro OpenSSL»Falta Git para Windows. Instalalo y volvé a correr.
«Falta GitHub CLI» / «no tiene sesión»Instalá GitHub CLI y corré gh auth login.
«El certificado no corresponde a esta clave privada»Ese .cer se pidió con otra solicitud. Pedí uno nuevo subiendo la de firma-ios.
«Ya hay una clave privada»No es error: la usa. Si querés empezar de cero, mové la carpeta firma-ios a otro lado.
Se cortó a la mitadVolvé a correr el script: lo que ya está hecho no se repite.
La compilación falla en GitHubMandá una captura del paso en rojo de Actions → Publicar iOS.
«The bundle version must be higher»Esa versión ya se subió: hay que subir codigo en version.properties.

Después

  • Instalá TestFlight en el iPhone y probá la app.
  • Cargá contenido en el panel y corré Actions → Capturas para la tienda.
  • Completá la ficha con docs/app-store/ficha.md y mandala a revisión.
